# نیازمندی‌ها و جریان‌های کاربری — پیراهن مردانه

نسخه: ۱.۰  
آخرین به‌روزرسانی: ۲۰۲۶-۱۰-۰۷  
وضعیت: پیش‌انتشار (noindex)

## ۱. هدف محصول

فروشگاه تخصصی **پیراهن مردانه** با دامنه `pirahanmardane.ir`  
استک: Next.js 15 + Supabase + Vercel + Cloudflare + R2

## ۲. نقش‌ها (Actors)

| نقش | توضیح |
|-----|--------|
| مهمان (Guest) | مرور کاتالوگ، سبد، بخشی از چک‌اوت |
| مشتری (Customer) | حساب، آدرس، سفارش، مرجوعی، نظر |
| ادمین (Admin) | مدیریت کامل فروشگاه |
| سیستم (System) | کرون بک‌آپ، رزرو موجودی، استعلام ارسال |

## ۳. نیازمندی‌های کارکردی (خلاصه)

### کاتالوگ
- مشاهده محصولات، دسته، برند، فیلتر و جستجو
- صفحه محصول با تصویر، قیمت، موجودی، مشخصات، نظرات

### سبد و سفارش
- افزودن/حذف/تغییر تعداد
- چک‌اوت چندمرحله‌ای
- انتخاب روش ارسال (پست، تیپاکس، اسنپ‌باکس، الوپیک، پیک، حضوری)
- ثبت سفارش و پیگیری

### حساب کاربری
- ورود / پروفایل / آدرس‌ها
- تاریخچه سفارش
- درخواست مرجوعی
- حذف حساب

### ادمین
- محصولات، دسته، برند، ویژگی
- سفارش، موجودی، تخفیف
- نظرات، مرجوعی، تماس، بلاگ
- روش‌های ارسال + تنظیم API
- بک‌آپ، آنالیتیکس، SEO

### خارج از محدوده فعلی (عمدی)
- درگاه پرداخت واقعی / کیف پول / اقساط
- باشگاه مشتریان کامل
- PWA
- چت زنده
- چندزبانه
- ایندکس گوگل (فعلاً noindex)

## ۴. جریان‌های کاربری اصلی

### UF-01 — خرید (مشتری)
1. ورود به فروشگاه  
2. جستجو یا مرور دسته/برند  
3. مشاهده محصول و افزودن به سبد  
4. چک‌اوت: سبد → گیرنده → ارسال → پرداخت → نتیجه  
5. مشاهده سفارش در داشبورد  

### UF-02 — مرجوعی
1. ورود به داشبورد → بازگشت کالا  
2. انتخاب سفارش واجد شرایط (`shipped` / `delivered`)  
3. ثبت دلیل  
4. ادمین: تأیید / رد / دریافت / عودت وجه  

### UF-03 — نظر محصول
1. خریدار نظر ثبت می‌کند  
2. تا تأیید ادمین عمومی نمی‌شود  
3. ادمین تأیید/رد و در صورت نیاز پاسخ می‌دهد  

### UF-04 — مدیریت ارسال (ادمین)
1. تعریف/ویرایش روش ارسال  
2. فعال/غیرفعال  
3. تنظیم API (تیپاکس، اسنپ، الوپیک)  
4. مشتری در چک‌اوت روش‌های فعال را می‌بیند  

### UF-05 — تماس
1. مهمان/مشتری فرم تماس را پر می‌کند  
2. Rate limit اعمال می‌شود  
3. ادمین پیام را در پنل می‌بیند  

## ۵. معیار پذیرش کلی (DoD سطح محصول)
