# فاز ۱۴ — مرجوعی

وضعیت: **بسته (استاندارد عملی ایران)**

تاریخ: ۲۰۲۶-۱۰-۱۸

## محدوده
- درخواست مرجوعی توسط مشتری (داشبورد → بازگشت کالا)
- فقط سفارش‌های `shipped` / `delivered`
- مهلت ۷ روز از زمان ارسال/ثبت
- دلایل آماده + توضیح آزاد
- وضعیت‌ها: pending → approved / rejected → received → refunded
- یادداشت ادمین قابل مشاهده برای مشتری
- اعلان به مشتری هنگام تغییر وضعیت
- بازگردانی موجودی هنگام received/refunded

## DoD
- [x] مشتری درخواست ثبت می‌کند
- [x] سفارش غیرمجاز رد می‌شود
- [x] درخواست تکراری باز مسدود است
- [x] ادمین وضعیت را تغییر می‌دهد
- [x] موجودی در دریافت کالا برمی‌گردد
- [x] وضعیت فارسی + یادداشت در پنل مشتری
- [x] صفحه سیاست مرجوعی `/returns`

## خارج از محدوده
- پیکاپ مرجوعی توسط پست به‌صورت خودکار
- عودت وجه خودکار به درگاه (دستی توسط ادمین با وضعیت refunded)
