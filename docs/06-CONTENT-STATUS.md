# فاز ۶ — محتوا و صفحات ثابت

وضعیت: در حال تکمیل (پیش‌انتشار)

## محدوده
- صفحات ثابت فروشگاه (درباره ما، FAQ، راهنمای سایز، ارسال، مرجوعی، حریم خصوصی، شرایط)
- ویرایش از پنل ادمین `/admin/pages`
- قالب‌های اختصاصی (FAQ آکاردئون، مراحل ارسال، CTA مرجوعی)

## انجام‌شده (فنی)
- مسیرهای /about /faq /size-guide /shipping /returns /privacy /terms
- پنل ادمین صفحات
- site_settings / محتوای استاتیک قابل ویرایش

## معیار پذیرش (DoD)
- [ ] /about بدون خطا و با متن واقعی
- [ ] /faq حداقل ۵ سوال متداول
- [ ] /size-guide راهنمای سایز قابل استفاده
- [ ] /shipping و /returns متن شفاف دارند
- [ ] /privacy و /terms حداقل متن حقوقی پایه
- [ ] ادمین می‌تواند متن را از /admin/pages عوض کند

## خارج از محدوده
- بلاگ کامل سرمقاله (می‌تواند بعداً غنی شود)
- ایندکس گوگل (noindex عمدی)
