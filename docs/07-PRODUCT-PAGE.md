# فاز ۷ — صفحه محصول (PDP)

## انجام‌شده
- گالری تصویر + تامب‌نیل + لایت‌باکس تمام‌صفحه
- زوم هاور دسکتاپ (transform-origin روی نشانگر)
- مشخصات از product_attribute_values (ProductSpecs)
- محصولات مرتبط هم‌دسته (RelatedStrip) + قیمت
- Buy box واریانت، راهنمای سایز، نظرات، تاریخچه قیمت

## معیار پذیرش
- [ ] هاور روی تصویر (دسکتاپ) زوم می‌کند
- [ ] کلیک تصویر لایت‌باکس باز می‌کند
- [ ] مشخصات در صورت وجود attribute نمایش داده می‌شود
- [ ] محصولات مرتبط در پایین صفحه دیده می‌شوند
