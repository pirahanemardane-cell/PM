# فاز ۱۱ — پرداخت

وضعیت: **شروع شده**

## محدوده
- ایجاد سفارش از چک‌اوت
- اتصال درگاه (یا حالت تست / واریز)
- بازگشت از درگاه و verify
- وضعیت سفارش: در انتظار پرداخت / پرداخت‌شده / ناموفق
- صفحه نتیجه پرداخت (موفق / ناموفق)
- جلوگیری از دوباره‌پرداخت روی سفارش بسته‌شده

## خارج از محدوده
- لغو و مرجوعی توسط مشتری (فاز ۱۲)
- گزارش مالی پیشرفته ادمین

## معیار پذیرش (DoD)
- [ ] از چک‌اوت سفارش ساخته می‌شود
- [ ] مسیر پرداخت (درگاه یا دستور واریز) مشخص است
- [ ] بعد از پرداخت موفق وضعیت سفارش به‌روز می‌شود
- [ ] پرداخت ناموفق / انصراف پیام مناسب دارد
- [ ] سفارش پرداخت‌شده دوباره قابل پرداخت نیست

## یادداشت پروژه
- مدل «در انتظار تأیید ادمین» برای برخی پرداخت‌ها از قبل مطرح شده
