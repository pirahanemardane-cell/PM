# فاز ۲۲ — تنظیمات عملیاتی فروشگاه

وضعیت: **بسته**

تاریخ: ۲۰۲۶-۱۰-۲۰

## محدوده
- در `/admin/settings`:
  - ارسال رایگان روشن/خاموش
  - حداقل مبلغ ارسال رایگان
  - پیامک سفارش روشن/خاموش (`order_sms_enabled`)
  - تلفن و ایمیل پشتیبانی
- ذخیره در `site_settings`

## موکول
- فاز ۱۷: پترن ملی‌پیامک برای ارسال واقعی SMS
