# فاز ۱۵ — نظرات محصول

وضعیت: **بسته (استاندارد عملی ایران)**

تاریخ: ۲۰۲۶-۱۰-۱۸

## محدوده
- ثبت نظر فقط توسط خریدار واقعی محصول
- امتیاز ۱ تا ۵ ستاره
- عنوان اختیاری + متن (بدون لینک/تصویر)
- تأیید ادمین قبل از نمایش عمومی (`is_approved`)
- برچسب خریدار تأییدشده (`is_verified`)
- پاسخ فروشگاه (`admin_reply`)
- میانگین و تعداد نظر روی محصول (trigger دیتابیس)
- اعلان به کاربر هنگام تأیید نظر
- به‌روزرسانی زنده لیست نظرات (Realtime)

## DoD
- [x] فقط خریدار می‌تواند نظر بدهد
- [x] نظر تا تأیید ادمین عمومی نیست
- [x] ادمین تأیید / لغو تأیید / پاسخ
- [x] نمایش ستاره و پاسخ فروشگاه در PDP
- [x] جلوگیری از نظر تکراری
- [x] آمار میانگین محصول

## خارج از محدوده
- عکس در نظر
- رأی مفید بودن نظر
- گزارش تخلف توسط کاربران

## تأیید مالک
- ادامه مسیر استاندارد پس از فاز ۱۴
