# فاز ۵ — کاتالوگ محصولات (وضعیت)

## انجام‌شده
- جدول products + sale_price / compare_at_price / brand_id / category_id
- واریانت (product_variants): قیمت، موجودی، سایز، رنگ
- تصاویر محصول (product_images) + R2
- ویزارد ادمین: /admin/products/new و ویرایش
- لیست محصولات ادمین: /admin/products
- فروشگاه: لیست، صفحه محصول، افزودن به سبد با واریانت
- برند و دسته در پنل ادمین

## معیار پذیرش (DoD فاز ۵)
- [ ] حداقل یک محصول published با واریانت فعال و موجودی > 0
- [ ] قیمت از واریانت در فروشگاه درست نمایش داده می‌شود
- [ ] افزودن به سبد با سایز/رنگ ممکن است
- [ ] ادمین می‌تواند محصول جدید بسازد و منتشر کند
- [ ] محصول بدون واریانت در فروشگاه «ناموجود» یا ساخته‌شده با واریانت پیش‌فرض است
