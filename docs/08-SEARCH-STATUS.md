# فاز ۸ — جستجو (تکمیل‌شده)

## انجام‌شده
- جستجوی پایه + suggest (محصول/برند/دسته/بلاگ)
- Full-text سبک: name + short_description + slug
- Typo tolerance سبک: نرمال‌سازی فارسی + نقشه غلط‌های رایج
- Recent searches: localStorage در باکس جستجو
- search_queries لاگ + POST /api/search/log
- Analytics: /admin/search-analytics
- No-result: پیام + لینک همه محصولات / محبوب‌ترین

## ظاهر
ساختار SmartSearch حفظ شده؛ فقط بلوک recent و no-result غنی‌تر اضافه شد.
