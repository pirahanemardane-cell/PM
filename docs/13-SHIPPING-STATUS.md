# فاز ۱۳ — ارسال

وضعیت: **محدود به پست (نرخ ثابت)**

## تصمیم مالک
- همه روش‌های ارسال به‌جز **پست** حذف/غیرفعال شدند.
- فعلاً فقط ارسال از طریق **پست** فعال است.
- نرخ ارسال **ثابت** است و از پنل ادمین (`/admin/shipping`) قابل تنظیم است.

## از قبل موجود

- [x] قیمت‌گذاری `fixed` (نرخ ثابت از فیلد fee)

## نحوه تنظیم نرخ
1. ورود به پنل ادمین → روش‌های ارسال
2. روی «ویرایش» روش پست
3. نوع قیمت: **ثابت**
4. هزینه (تومان) را وارد و ذخیره کنید
