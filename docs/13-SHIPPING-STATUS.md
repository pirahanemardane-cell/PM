# فاز ۱۳ — ارسال

وضعیت: **بسته (طبق تصمیم مالک — مدل عملی ایران)**

تاریخ بستن: ۲۰۲۶-۱۰-۱۸

## تصمیم مالک
- روش پیش‌فرض و فعال عملیاتی: **پست** با **نرخ ثابت** از پنل ادمین
- سایر روش‌ها (تیپاکس / اسنپ / الوپیک) در زیرساخت باقی مانده‌اند؛ برای فعال‌سازی واقعی نیاز به کلید API و قرارداد است
- پیگیری: **کد سفارش** + **کد رهگیری پست** + لینک tracking.post.ir

## DoD — انجام‌شده
- [x] Shipping methods (CRUD ادمین)
- [x] اتصال چک‌اوت به روش‌های فعال DB
- [x] **Shipping zones** (جدول + پنل ادمین + فیلتر در چک‌اوت بر اساس استان/شهر)
- [x] **Free shipping rules** (آستانه مبلغ از site_settings + اعمال در quote)
- [x] وزن محصول در محاسبه (weight_grams واریانت؛ پیش‌فرض ۴۰۰ گرم)
- [x] Tracking number روی سفارش + نمایش به مشتری + لینک پست
- [x] وضعیت ارسال/تحویل (`shipped` / `delivered`) + اعلان
- [x] به‌روزرسانی زنده وضعیت برای مشتری (Realtime + polling)
- [x] اسکلت API تیپاکس / اسنپ‌باکس / الوپیک (فعال با کلید در پنل ادمین)
- [x] چاپ برچسب ارسال / بارنامه ساده (`/admin/orders/[id]/label`)
- [x] نرخ ثابت پست از ادمین

## خارج از محدوده (عمدی تا قرارداد)
- قرارداد production و کلید واقعی تیپاکس/اسنپ/الوپیک (مالک باید در ادمین وارد کند)
- چاپ بارنامه پیچیده چندصفحه‌ای شرکت حمل
- geocode خودکار آدرس مشتری برای پیک (مختصات انبار در api_config قابل تنظیم است)

## تست دستی (مالک)
1. چک‌اوت: فقط روش‌های فعال؛ با استان، فیلتر zone
2. سفارش بالای آستانه رایگان → هزینه ارسال ۰ (اگر free shipping روشن باشد)
3. ادمین: وضعیت → shipped + کد رهگیری پست
4. مشتری: پیگیری سفارش با UUID → وضعیت + کد رهگیری + لینک پست
5. ادمین: چاپ برچسب سفارش
